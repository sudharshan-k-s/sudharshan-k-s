## 🌳 ForestWatch — Satellite Image-Based Deforestation Detection

ForestWatch is my **major college project** focused on detecting forest loss
using satellite imagery and deep learning.

The project analyzes multi-temporal satellite data to identify deforestation
while addressing challenges such as seasonal vegetation changes and varying
terrain conditions.

### 🛠️ Tech Stack

- Python
- TensorFlow
- ResNet50
- CNN
- Sentinel-1 SAR
- Sentinel-2
- NDVI
- Google Earth Engine
- QGIS
- Google Colab

### 🎯 Key Features

- Multi-temporal satellite image analysis
- Sentinel-1 SAR and Sentinel-2 optical data
- NDVI-based vegetation analysis
- Deep-learning-based forest-loss detection
- Image preprocessing and feature extraction
- Model evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
